# nvim-dojo — browser demo

A playable, five-challenge taste of nvim-dojo, a Neovim plugin that drills
plugin-specific workflows: Telescope pickers, live grep, and chaining a search into
the quickfix list.

**This repository is generated.** Every file here is published automatically from the
plugin repo's `web/` directory. Edits made here are overwritten on the next publish.

Static files, no build step and no dependencies. Serve the directory and open
`index.html`, or embed it in an iframe.

It is keyboard-driven, so an embedded frame must be clicked before it receives
keystrokes; the page shows a "Click to play" veil until it has focus.

The plugin itself is a private repository, so this README deliberately links nowhere.
