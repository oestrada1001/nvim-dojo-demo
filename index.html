nvim-dojo

Drill the toolchain you actually use.

Most Vim trainers stop at hjkl. The hard part of Neovim is not motions — it is reaching for the right plugin, fast, without thinking.

Five challenges, about a minute. You will open a fuzzy finder, narrow 150 files down to one, search file contents, and chain a search into the quickfix list.

  • <space>ff find files   <space>fg live grep
  • Type to filter   Tab multi-select   <CR> open
  • <C-q> send to quickfix   Esc close
  • : command line — :Dojo hint if you get stuck

This simulation teaches one set of keys. The real plugin never checks which key you press — it checks that the picker actually ran, so your own bindings work unchanged.
